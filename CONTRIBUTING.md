# Contributing

Thanks for helping improve Comfy Studio.

1. Fork the repository and create a focused branch.
2. Keep runtime data, credentials, generated media, and personal model inventories out of commits.
3. Run `npm test` and `node --check server.js` before opening a pull request.
4. Explain the user-facing behavior and include screenshots for visual changes.

Use GitHub issues for bugs and feature proposals. Report security problems through a private GitHub security advisory as described in `SECURITY.md`.
